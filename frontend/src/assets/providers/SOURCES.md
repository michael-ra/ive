# Provider marks

Downloaded from the providers' own sites on 2026-10-14. These marks identify
the services used in IVE; they remain the property of their respective owners.
They are bundled locally, rendered without stretching or recoloring, and never
used as IVE's own identity. No remote logo requests occur at runtime.

- `claude.svg`: **Claude Spark - Clay.svg**, Anthropic's [official press kit](https://anthropic.com/press-kit), linked from its [newsroom](https://www.anthropic.com/news).
- `anthropic-light.svg` / `anthropic-dark.svg`: **Anthropic symbol - Slate.svg / Ivory.svg**, same press kit.
- `openai-light.svg` / `openai-dark.svg`: **OpenAI-black-monoblossom.svg / OpenAI-white-monoblossom.svg**, [official logo package](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip), [brand guidelines](https://openai.com/brand/). Codex uses this official OpenAI provider mark; it is not a fabricated Codex symbol.
- `gemini.svg`: [Gemini sparkle](https://www.gstatic.com/lamda/images/gemini_sparkle_aurora_33f86dc0c0257da337c63.svg), referenced by [Gemini](https://gemini.google.com/).
- `antigravity.png`: [Antigravity logo](https://antigravity.google/assets/image/antigravity-logo.png), referenced by [Google Antigravity](https://antigravity.google/). Antigravity and Gemini are separate brands.
- `google.png`: [Google G](https://www.gstatic.com/images/branding/googleg/1x/googleg_standard_color_128dp.png), Google's official static asset host.

All image files are byte-for-byte copies of those assets (or exact ZIP members).
Monochrome OpenAI and Anthropic marks use the supplied dark/light variants.
Unknown/custom engines receive a neutral CPU icon instead of a different brand.
